# Old Netlify address → jaytech9.com

Netlify → sign in → open the old **jaytech9** site → **Deploys** → drag the **netlify-redirect** folder onto
"Drag and drop your site output folder here". Every old link (e.g. jaytech9.netlify.app/contact) now goes
to the same page on jaytech9.com, and search engines move their results over.
